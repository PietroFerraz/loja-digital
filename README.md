# Loja Digital

Criar um site para vender produtos digitais com checkout online. Vendas únicas (não assinatura): o cliente paga uma vez por produto e recebe o produto digital. Usar Lovable Payments como processador de pagamento. O site ainda não tem nome nem marca — usar um nome provisório simples tipo "Minha Loja" e uma identidade visual limpa que eu possa ajustar depois.

This project was built with [Lovable](https://lovable.dev).
